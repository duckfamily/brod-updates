# brod-updates

Подписанные обновления стратегий обхода и списков сайтов для программы «Брод».

Программа раз в сутки скачивает `brod-update.json` (отсюда или с зеркала jsDelivr),
проверяет подпись ed25519 встроенным открытым ключом и принимает только версию новее
установленной. Файл без верной подписи программа отбрасывает.

Открытый ключ: `kmX5SMVctoGAJYMR9ibQVGobopIoKeJAF7aM0HB9DsM=`
